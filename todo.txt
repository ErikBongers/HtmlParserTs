HTML string tags
=================
Example:
--------
<div>This is {variable} !</div>   >>> this cannot work because we don't know how to find the div without an id!
<div id="title">This is {var1} and {var2} !</div>
<div id="title" class="flex {var1} {var2} row">...
<div id="[title]">This is {variable} !</div>  >>> this checks if title is a defined attribute.


This should result in
-----------------------
this.shadow.getElementById("title").node[n].nodeValue = "This is " + this.getAtt("variable").value + "...";
or better a mapping like:
{
    id: "title", [
        {
        target: "content",
        nodeIndex: <n>,
        parts:["This is ", {att:"var1"}, " and ", {att:"var2"}, " !"]
        }
    ]
}
